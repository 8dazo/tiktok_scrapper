# tiktok_scrapper

Unofficial TikTok API: scrape video/user metadata and optionally download media (no API key required).

| Package | Language | Install |
|---------|----------|---------|
| **tiktok-api** | Python | `pip install tiktok-api-unofficial` or use `tiktok-api/` |
| **tiktok-api-ts** | TypeScript/Node | `npm install tiktok-api-unofficial` or use `tiktok-api-ts/` |

- **Python:** see [tiktok-api/README.md](tiktok-api/README.md).
- **TypeScript:** see [tiktok-api-ts/README.md](tiktok-api-ts/README.md).
